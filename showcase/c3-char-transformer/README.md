# C3 — a character-level Transformer, and the walls it hit

A two-layer, two-head character Transformer trained with the **library-level** `grad`
(`stdlib/vjp.cml`, not the engine's `with_grad`): embedding lookup, layer norm, multi-head
attention with a causal mask, residual connections, a two-layer MLP, a softmax cross-entropy
loss, Adam. The model is the standard one; the reading is what the library can and cannot
differentiate today.

**The walls are the deliverable.** `WALLS.cn.md` is the list: minimal program, verbatim
diagnostic, classification, and what would have to change for each one to fall.

## What is here

| file | what it is |
|---|---|
| `train.cml` | The model and the training loop, at the parameters the author asked for: context 8, width 16, 2 heads, 2 layers, vocabulary 28. It stops at `import { vjp } from vjp` (wall 1). |
| `forward.cml` | The same model, same seed, same corpus, with the transform and the loop removed, so the forward half can be measured while the transform cannot be imported. Nothing is reduced. |
| `probes/` | Eighteen minimal programs, one construct each: `grad` at a scalar, `jvp` at a scalar, `jvp` across a call, the matrix product, softmax, an axis reduction, reshape, a table row, the causal mask, two parameters, a `with` parameter tree, `grad` at a model, one attention block, and the element types of `layer_norm`, a drawn tensor, a looked-up row and a constant mask. |
| `probe.py` | Runs the probes, groups them by the wall each hit, and pins the expected answer of every one: a probe that moves is a wall falling or a regression, and either way the report has to be rewritten. |
| `block_forward.cml`, `block_engine_grad.cml`, `block_library_grad.cml` | The smallest attention block — two tokens, one dimension, one head — on the three paths: forward only, the engine's `with_grad`, the library's `vjp`. |
| `baseline/block.py` | The same block in numpy: the forward value and the six partial derivatives by hand, cross-checked against a central finite difference. |
| `compare.py` | Compares the three, writes `RESULTS.md`, and prints one line per reading with its tolerance. |
| `make_corpus.py`, `corpus.txt` | The committed 96-line corpus (4278 bytes, 26 distinct characters) and the program that generated it. |

## The readings

```
$ python showcase/c3-char-transformer/probe.py
probes total=18 ok=5 refused=13

$ python showcase/c3-char-transformer/compare.py
c3 compare row=forward                            camel=0.455920556651  reference=0.455920556651  error=0.000e+00   ok=True
c3 compare row=gradient (engine with_grad)        camel=-0.021925348589 reference=-0.021925348589 error=0.000e+00   ok=True
c3 compare row=gradient (library vjp)             camel=absent          note=refused: stdlib/vjp.cml:78:47   ok=True
c3 compare: PASS
```

The library row says `refused` and the table still says `PASS`: the example records the refusal as
its finding. A forward value or an engine gradient outside its tolerance would be a `FAIL`, because
those are this example's own arithmetic, not the library's.

| wall | construct | today |
|---|---|---|
| 1 | the library's `vjp` composition | does not compile (`stdlib/vjp.cml#vjp`, line 78) — this is what blocks every gradient |
| 2–7 | forward rules for `matmul`, `softmax`, `mean_axis`, `reshape`, `take`, `subtract` | missing (`jvp` has no rule for any of them) |
| 8 | a constant tensor in one element type | no spelling: `full::<f32>(shape, -1000.0)` refuses, `reshape` will not take a `bool[]` |
| 9 | a model in one element type | the forward pass stops at `(f32[..], float[..])`; `layer_norm`, `normal`, `take` were cleared by probes 16–18 |

By the author's four categories: **missing rule 8** (walls 2–7, plus 8 and 9, which are missing
type/constant rules rather than missing differentiation rules), **transform refusal 1** (wall 1),
**missing batch rule 0**, **performance 0**. Walls 8 and 9 do not fit the four; they are listed
separately rather than forced into one.

## Running it

The whole thing is one plan file. It is `tier = "milestone"` under `test/plans/perf/`, so the fast
gate does not run it:

```
node scripts/test.js test/plans/perf/showcase_c3.plan.toml          # the four entries
```

or, by hand:

```
camel showcase/c3-char-transformer/forward.cml --arg corpus=showcase/c3-char-transformer/corpus.txt
camel showcase/c3-char-transformer/train.cml --arg corpus=... --arg mode=train --arg steps=2
python showcase/c3-char-transformer/probe.py
python showcase/c3-char-transformer/compare.py
```

`WALLS.cn.md` is in Chinese; it is the deliverable. `RESULTS.md` is generated by `compare.py` and
is not committed, because it is a reading of one machine's binary rather than a source file.
