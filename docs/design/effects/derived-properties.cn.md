# 由足迹回答的性质

## 初心

遍要问的问题都很具体：这个节点能不能删，能不能和另一个合并，能不能挪到别处，能不能在遍里先替它算出来，能不能放到设备上跑，能不能写在规则的条件里。这些问题的答案都来自同一件事，就是这个节点访问了什么，也就是它的足迹。

所以足迹只算一次，每个问题是对足迹的一个判定函数，各在一处定义。任何遍、任何后端都问这一处，不另存一张表，也不按名字去认。一件事若有两份答案，迟早会不一致：同一个节点被一处判成可摆、被另一处判成不可摆，或者一次编辑让其中一份过期。

框架里的四条等式（丢弃、复制、交换、擦除）见 [`README.cn.md`](README.cn.md)。本页讲足迹从哪里来，以及每个问题怎样由足迹回答。

## 足迹从哪里来

- **算子只有一份声明**：就是它在 `.cml` 里写的 `pure`、`uses`（以及其中的 `var` 写）、`panic` 与分配。C++ 一侧读这份声明，不另立纯度表或访问表。
- **没有声明的算子按有效应对待**（原则 3.3）：最多少优化，不会算错。一个算子节点找不到声明，就照此处理，不当作"什么都不碰"。
- **Camel 函数的足迹由编译器从函数体推出**（原则 3.3）：调用是一个锚点，它的足迹就是被调函数类型里的资源集。
- **读是依赖，不是效应**（原则 3.3）：读一个资源只说明它依赖那个资源的值。所以"纯"只承诺不写，读什么都可以。

## 资源怎样取键

足迹里的每一次访问都落在一个资源键上，冲突与否按键比较：

- **外部资源**：键就是资源名（`fs`、`console`……）。
- **句柄**（`Ref` 与其他 `#resource` 类型的值）：键是这个句柄本身。经句柄的读写落在它指向的盒子上。
- **草稿**：经一个节点句柄的访问，落在这个节点所属的草稿上。已提交的图不属于任何草稿，取不到草稿键。
- **只读资源**（`graph`、`spelling`）：没有写者，读它从不冲突。

两次访问冲突的条件是：落在同一个键上，至少一方是写，并且这一对访问不满足交换（见四条等式）。冲突的访问之间建顺序边，提交检查要求它们有先后。`EACH` 的各轮之间没有先后，所以体内与另一轮冲突的写会被拒绝（见 [`../repetition/README.cn.md`](../repetition/README.cn.md)）。

## 每个问题怎样回答

每个判定都只看足迹，以及足迹在当前这个程序值里的写集：

| 问题 | 谁问 | 判定 |
|---|---|---|
| 纯吗 | 用户的承诺、`map` 等对元素函数的要求 | 足迹里没有写 |
| 会故障吗 | 删除、合并、提前计算 | 声明里有 `panic`，或者体内有会故障的节点 |
| 可摆吗（能删、挪、合、重排） | 死代码消除、合并重复计算、调度 | 下面五项同时成立 |
| 能在遍里先替它算出来吗 | 常量折叠 | 可摆，并且输入都已知 |
| 能放到设备上跑吗 | GPU 放置 | 足迹为空 |
| 能写在规则条件里吗 | 规则的条件 | 不写；读草稿与读图都可以 |

可摆要五项同时成立：

1. **纯**：足迹里没有写。
2. **不对外部产生效应**：程序外没有人看得到它运行。
3. **不会故障**：在程序写它的地方运行，不会产生故障（原则 3.9）。丢弃、挪动或合并一个会故障的计算，会改变可观察的行为。
4. **会结束**。
5. **不读会被写的资源**：它读的键，在这个程序值里没有写者。

第五项问的是"这个程序值里有没有写者"，不是"整张算子表里有没有写这个键的算子"。一个只有 `get`、没有 `set` 的程序里，`get` 是可摆的；同一个程序里一旦有 `set` 写同一个 `Ref`，`get` 就不可摆了。

**带区域的节点**（分支、循环、`EACH`）代表区域里运行的东西：各项取区域内所有节点的合取。**调用节点**代表的是另一张图的内容：它的足迹是被调函数类型里的资源集，不去展开被调者的函数体。

## 几处具体的定法

- **`state` 模块**：
  - `get` 只读一个 `Ref`，是纯的，并声明对这个 `Ref` 的读。
  - `set` 与 `update` 写这个 `Ref`。
  - 读一个 `Ref` 没有故障路径：`Ref` 只能由 `ref(v)` 造出，盒子里总有值，类型系统保证 `get` 拿到的是 `Ref`。所以 `get` 不声明 `panic`；实现里检查句柄的那几个分支是不变式断言，不是用户可见的故障。若这个断言被触发，那是执行计划的释放点放错了，属于运行时缺陷。
- **草稿上的查询**：答案会随草稿编辑而变的（`nodes`、`inputs`、`kind`、`exit`……），声明对草稿的读。答案由句柄本身定死的（句柄之间的相等、`creation_id`），不声明。
- **能否先算**：不另立一张"不可先算"的表，由可摆与输入是否已知推出。
- **判定问图，不问缓存**：判定函数直接读这张图的事实。事实库里没有这张图时，不能落成"合法"或"可摆"这类看起来无害的默认值。
