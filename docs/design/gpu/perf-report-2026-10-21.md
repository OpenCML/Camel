# 外部性能报告（2026-10-21，v0.2.14，8 × RTX 3090，潜空间扩散模型训练）

由语言作者委托的 AI 在服务器上测得（摘要，原文由语言作者提供）：

- 同一份数学、同一批权重、同一个 batch：Camel 每步 0.66 s，PyTorch 0.03–0.045 s（15–50 倍）。
- 每步耗时与 batch 几乎无关（batch 1 与 8 都是 1.5 s，128 是 2.3 s）；训练进程 GPU 利用率 0–10%、显存 0.4–2 GB。
- 依赖链微基准：单算子约 70 µs，与张量大小无关；`mm` 链比纯逐元素链每轮多约 90 µs（≈ 单线程 CPU 上 128×128×128 GEMM 的时间）。
- 优化器（Adam + EMA + 梯度范数，约 40 个叶子 × 3–5 个逐元素算子）每步约 0.19 s。
- 编译启动约 73 s。
- 业务侧绕行：主机上逐元素构造 one-hot（每步 424 万次）——改到设备上后 1.16 → 0.66 s/步；缺 embedding gather 与其 scatter-add 反向（v0.2.16 起已有 `take`）。
- 希望：gather/scatter、训练步的图捕获（CUDA Graph）、异步下发与显存池、常用融合、`run_device` 边界与同步的说明。

协调者的初判：主要计算并不在 GPU 上——只有显式区域进 GPU，反向、优化器、形状操作多在 CPU 单线程上逐算子执行，每个算子付分配、回收与分派的固定成本。
