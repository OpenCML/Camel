# 源文件里的一句注释，算不算一次"直连"？

**问：`GraphDraft` 直连账本数的是**连接**，还是**类型名出现过几次**？一句注释在 `src/` 里写到这个类型，该不该进 `references`？默认建议：**照今天的口径算（算），不改定义**——本次 +1 已在 `97bb9f16d` 记账并逐笔点名，见 §3。若作者裁定"注释不算"，则口径要改成"只数代码行"，那是一次定义变更，要连带把历史上所有注释项一起重记（§2 给了量）。**

## 1. 让这个问题变成问题的读数

`4e7033b00` 上 `test/cases/runtime/graph_draft_ledger/check.mjs` 原文：

```
[LEDGER] files 35 <= 35 references 307 <= 306 constructions 1 <= 1 decode 4 <= 4
[LEDGER] RED references rose from 306 to 307 (+1)
```

四条里只有 `references` 超 1，`files` / `constructions` / `decode` 都在基线内。逐笔拆开（`be25353a8` 是最后一次记账，之后到 `develop`）：

| 提交 | 净变化 | 是什么 |
| --- | --- | --- |
| `106b20d79` 同步链谓词 | **+2** | `isChainStatement` 从 `GraphDraft` 的成员变成自由函数，于是类型在声明（`include/camel/runtime/draft.h`）和定义（`src/runtime/graph.cpp`）各写一次，而成员只写一次。**同一个问题，写在了两个地方。** |
| `5573ee591` 区域是什么 | **+1** | `src/runtime/draft_regions.cpp` 里的一句注释：解释"每个 draft 都带自己的体区域"时提到了 `(GraphDraft)`。**这不是连接，是说明。** |
| `3609d015a` 用 epoch 命名 | **−2** | `DraftGraphBuilder::fromDraft` 删掉了，声明和定义都删。**这是账本在正常工作。** |

净 +1。也就是说：**账本这次红，是"一句注释 + 一次重构"和"一次真删除"抵出来的 1**，没有多出一个直接连到 draft 的居民。

## 2. 口径本身今天是怎么写的

`check.mjs` 的头注释把定义写死了：**"`src/`、`include/`、`modules/` 下整个词 `GraphDraft` 的事务外引用"**，并且明说 **"它不读 `test/`、`docs/`、`stdlib/`，所以这个文件和账本页可以随便提 `GraphDraft`"**。

作者已经把"散文里提这个类型不算连接"这条意思表达过了，**只是用路径实现**（排除 `docs/`），没有用"注释 vs 代码"实现。于是出现了今天这个不对称：`docs/` 里提一百次不算，`src/` 里一句 `//` 算一次。

现存注释项的量：`graph.h:303`、`graph.h:430`、`draft_regions.cpp:268` 等都是 `///` 或 `//` 行，且**已经在历史基线里**（`306` 这个数就含它们）。所以"注释不算"不是一次局部修补，是一次全量重记。

## 3. 默认建议与代价

**默认（已执行）：口径不动，`97bb9f16d` 把基线记到 `307`，并在提交信息里逐笔点名 `106b20d79` / `5573ee591` / `3609d015a`。**

| 路 | 做法 | 代价 |
| --- | --- | --- |
| **甲（默认，已做）** | 口径不动，记 `307`，逐笔点名 | 基线里永久含"注释/重构"类噪音；下一次同类重构还会让账本红一次，要靠人再点名一次 |
| 乙 | 改口径为"只数代码行"（去掉 `//`、`///`、`/* */`），全量重记 | 数会明显低于 306；要写一个 C++ 注释剥离器，`//` 出现在字符串里的情况要处理；**定义变更后，历史行与今天不可比** |
| 丙 | 不动口径也不记账，把这条测试标成已知失败 | **作者明确禁止**（口径见本轮任务书）。不采纳 |

**为什么默认选甲**：`--record --force` 是账本自己为"解释过的上涨"准备的通道，它会把这 5 行 diff 大声打出来；而改定义会让 `306` 这个历史序列断掉，代价比留一条注释噪音大。**这不等于"调高基线把增长盖掉"**——增长被逐笔点名了，而且其中真有 −2 的下降同窗口发生。

**作者若裁定乙**：本页的 `307` 要回退，改口径后按新数重记，并说明历史行不可比。
