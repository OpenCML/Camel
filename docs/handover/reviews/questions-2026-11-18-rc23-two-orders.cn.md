## 二、为什么它现在进不了 GATE —— 两条实测证据

程序：`let n = match k { case 3 => 0; case _ => sync { q(5); return 0; } }; null;`

期望 `P 5`，实际空。报 `The branch is never executed: nothing needs what it gives`。

**证据 (a)：`q(5)` 连 `chains` 都进不去。**
`case _` 这个臂**交出的值是共享常量**（落在 region 0），于是 `exitInRegion` 失败，`builder_diagnostics.cpp:628`「the exit is not a node of this region」把这个臂的**每一条写都 skip 掉**。

**证据 (b)：就算进去了也没用 —— 这个臂的值没有读者。**
`n` 没人读，所以 `match` 的 JOIN 连的是一个没人读的值。**只有 JOIN 换位能承重**，而那条同步边正是 `seal` 拒绝的**跨块边**。

⇒ 所以「把写放进 GATE 的输入 ⇒ GATE 就被需要」在 rc23 上**没有一条能承重的边可用**。**这是块切面的问题，不是记不记得住的问题。**
