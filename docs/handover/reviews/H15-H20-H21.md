## H15 待决问题的答复（协调者按授权裁定，已写入设计原则 5.1）

1. **分支臂里的 `return`**：取**读法 B**。臂里的 `return` 给出的是臂的值，它的期望类型来自臂所在的位置（`match` 的期望类型；没有时与其他臂一起确定），与函数声明的返回类型无关。种子 16 移回批次。
2. **数组字面量的元素、结构体字面量的字段**：都是"有期望类型的位置"，按同一规则取类型：`let xs: float[] = [1, 2.0]`、`let p: P = { a: 1, b: 2.0 }` 都合法。没有期望类型时，同一数组里的字面量按"整数 < 小数 < 虚数"取最宽的一种（与 Go 相同），`[1, 2.0]` 是 `float[]`。
3. **`match` 的模式字面量**：取被匹配值的类型，`match x { case 3 => … }`（`x: f32`）合法。
4. **折叠范围**：整数字面量之间的位运算（`&`、`|`、`^`、`<<`、`>>`）也在编译期精确计算；`&&`、`||` 不必。
5. **`let` 常量与字面量的分界**：维持现状。`let` 绑定的值有确定的类型（取默认类型），之后与变量一样不做隐式转换；`0.1 + 0.2` 与 `let a = 0.1; a + 0.2` 的差别在语言参考中醒目说明。
6. **折叠表达式越界的诊断位置**：指向整条表达式。
7. **两种"放不下"的诊断合并**：统一为 `LiteralNotRepresentable`，消息引用源码文本，按原因给出"超出范围"或"会被截断"（如 `1.9` 赋给 `int`）。
