# 残差是图的属性，元组项数是类型的属性：让 `split` 的两半项数由谁定

> **问什么**：`split` 交出的残差元组，项数该由**图**定（`f(x)=x` 是 0 项、`x*x` 是 1 项、`x*x*y` 是 3 项），
> 还是由**类型**定（每个值参数一项）？两条路今天给出了不同的数，需要一次拍定。
> **堵着谁**：`split` 的第二半要不要**重算**没被抬过去的残差；以及 M4 组装 `vjp` 时
> `transpose` 收多少项残差。
> **为什么我不自己定**：它决定一个进标准库签名的形状，而且要把 `split` 从 kernel 形式改成 pass 形式——
> 这是编译流程的改动，不是写法选择。

## 今天实测到的事实（都在 `develop` 上，读数逐字）

```
f(x,y)= x*x*y (x=3,y=2):  residuals=3 carried=2 slots=2 agree=yes
恒等图 f(x)=x:            residuals=0 carried=0 slots=1 agree=yes
g(x)=x*x (x=3):           residuals=1 carried=1 slots=1 agree=yes
```

- **`residuals=` 是图算的**（`residualsOf`：从切线侧走到一个已经在结果侧的节点，那个值就是跨切的残差）。
  恒等图**真的是 0**，不是凑的。
- **`slots=` 是类型算的**（`FuncTypeResolver::resolve(with, norm)` 只看得见 `type_vec_t`），
  今天只能表达“每个值参数一项”，所以恒等图是 1。
- **`carried=` 是元组装得下的那几个**。
- `x*x*y` 为什么是 3：第二个 `mul` 的规则读的是 `t0 = x*x` 这个**乘积本身**，跨切的是 `x`、`y`、`x*x` 三个值。
  签名只有 2 个槽，第三个没处放，于是后一半**重算** `x*x`（拿抬过去的 `x` 再乘一次）。
  数字因此仍然是对的：`dfdx= 12.0`、`dfdy= 9.0`，与解析值逐位相同。

**一层靠类型做不到，说清了**：`f(x)=x` 与 `f(x)=x*x` 的 lifted 类型**完全相同**（`(float,float)=>(float,float)`），
所以任何只看类型的函数都不可能对一个给 0、对另一个给 1。运行时改 `funcType` 也没用：
调用点已经按静态类型定死了参数个数。

## 三条路

### A（默认建议，今天正在走）——项数归类型，缺的项在后一半重算

- 代价：**重算**。今天 `x*x*y` 重算 1 个节点；一个被切两次的表达式会重算更多。
- 好处：**不改编译流程、不改三个模块接口**，数字今天就是对的；`residuals=`/`slots=` 两行读数把差额摆在明面上，
  `agree=yes` 保证没有值被放到错误的半边。

### B——`split` 走 **pass 形式**（`reinterp<jvp>` 那一路：图在手时再定类型）

- 代价：`split` 从 kernel 变成 pass；调用点从“按静态类型定型”变成“先跑一遍再定型”，
  要动 `modules/transforms` 的接口，`stdlib` 里 `vjp` 的组合写法也会跟着变。
- 好处：**项数归图**，恒等图 0 项、`x*x*y` 3 项，**不再重算**；`ResidualsOf<F>` 与图天然一致。

### C——`ResidualsOf<F>` 做成**在 GIR 上求值**的类型函数

- 代价：要在编译期给类型函数一条“看图”的通路（设计 6.1 那片空白），比 B 小、比 A 大；
  它同样要求调用点的定型晚于建图。
- 好处：名字与函数还是类型层的，`stdlib` 的写法不用改；`transpose` 只按项数收残差。

## 判据

**改完能删掉什么**：B 能删掉“重算”这一整类代码与它的两行诊断（`carried`/`agree` 不再需要，
因为不会再有不一致）；C 能删掉同样的重算，但保留类型函数的写法；**A 什么都删不掉**，
只保证今天正确。**若 M4 组装之后重算的代价开始出现在读数里（比如 `vjp` 的秒数或节点数明显变大），那就是该走 B/C 的信号。**

## 默认与正在做的事

**按 A 继续**：`split` 保持 kernel 形式，项数按类型给、缺的项在后一半重算；
`residuals=`/`slots=`/`agree=` 三行诊断留在读数里当证据。
**同时**把 B 的入口留好：`split.h` 里 `residualsOf` 已经能吃一个 `GCGraph`，
走 pass 形式时它直接就是第一段，不需要重写。
