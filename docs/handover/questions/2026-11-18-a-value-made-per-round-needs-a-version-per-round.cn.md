# 问：一轮造一个值、循环之后还要读它，计划该怎么数它？

`2026-11-18`｜基线 `origin/develop = 2e1e77324`｜引 `ad44fca33`（那条「还是一个泄漏」的注释）、`7d06ad174`（循环出口归还）、`5975022fe`（本条的测量与那个故意的红）

## 一、为什么必须问

审查项 10 说 `ad44fca33` 留了一条「知道了但没量」的泄漏，要求先量、再修或写清为什么修不了。量出来的结果是：**那条注释说的形状已经不漏了，而它旁边那个形状是坏的，坏的方向相反。**

```
① 注释说的形状（CALL/FILL 在循环**外**造值、循环里读、循环后不读）
   `test/probe/refleak/call_box_loop_outer.cml`：四后端一致 `created=1 released=1 live=0`
   ⇒ 它要的那个「循环之前的位置」就是 LOOP 节点自己的位置，`applyRefEntriesForLoopExit` 在循环离开时执行一次
   ⇒ 泄漏 0。**修前 0、修后 0**：这条没有可修的东西，只有「一条记录被后来的改动顺手解决了」

② 同一个族里没被记录过的形状（一轮造一个值、cell 留着）
   `test/probe/refleak/box_of_a_round.cml`：`var last = escaped_box(0)`，循环里每轮 `last = escaped_box(i)`，循环后 `state::get(last)`
   四后端一致读：`created=4 counted=4 released=2 live=2 disposed=2 ... found=4 missing=0`
   且循环后那次读撞上**已经归还**的盒子（"the value is not a reference"）
   ⇒ **四个盒子造出来，两个被还了两次（最后那个），两个永不归还**；程序本身也读不到正确结果
```

**⇒ 所以这一问不是「漏了几个」，是「一个计划节点，能不能数清楚它在每一轮造的那个值」。**

## 二、为什么它是裁定而不是实现细节

一条 row 引用的是**一个节点**。而 `last = escaped_box(i)` 在计划里是**一个**节点、在运行里是**每轮一个**盒子。

```
计划能看到这个值的两处用途：
  (a) LOOP 自己读那个 state（它的 row 落在 `loop.position`，循环离开时执行**一次**）
  (b) 循环之后那次读（执行**一次**）
⇒ 两行各跑一次 = `released=2`，而运行造了 4 个盒子
⇒ 这不是「少写了一行」：**再多写一行也只会多还一次那个活着的盒子。**
```

两个方向都不对，而它们都不是在本函数里能选的：

```
· 逐轮归还（对的那一版）：盒子的死法是「下一轮把它从 cell 里覆盖掉」
  ⇒ 需要一行能指名「上一轮这个节点造的值」
  ⇒ 而「上一轮」不是节点身份的一部分 —— 这是**值的版本**，不是 row 的写法
· 消费者处保守（keep）：把双归还换成「每轮漏一个」
  ⇒ 数量上更像那条注释，但它是**把一个错答案换成一个更慢的错答案**，
    而且会让 `live` 从 2 变成 4 —— 读数变差，行为变对，却没有一行代码说明它为什么对
```

**⇒ 这条的核心是「节点 ↔ 值」的对应关系**：一个节点在一轮里造一个值，就必须有「这一轮的它」。那是表示层的问题（今天 `ExecPlan` 的值是节点下标），不是 `planRefRows` 的规则能补的。

## 四、乙那一批开工时必须先回答的两件事

```
① 「每轮一个值」是节点身份的一部分，还是节点的某个「轮次」属性？
   ⇒ 前者：一个值一个下标，循环体里的节点在计划里要按轮展开（行数会随轮数变，计划要先知道轮数）
   ⇒ 后者：值仍然一个下标，但行多一个「轮次」字段，执行器按轮次比对
   ⇒ **两条路的代价差一个数量级，而它决定计划还能不能在图之外算**
② 保守答案（keep）要不要保留成退路？
   ⇒ 若要：`kept` 已经是计划自己的词（`refKeptAt`），这一形状可以立刻读成「保留、不漏、不双还」
     ——**它不是修复，但它是「不返回一个正常形状的错答案」**
   ⇒ 今天没做这一步，因为 `live=4` 会让这个探针的读数比现在更差，
     而「读数更差、行为更对」需要作者点头，不是车道能自己决定的。
```

## 五、一处必须先记下的判断依据

```
· 那条注释的原文（`ad44fca33`）：值由 CALL/FILL 造、hold 必须落在循环轮里时「仍然保留」
  ——**它描述的是漏；今天量到的是双还**。同一个「一个节点、多轮」的病根，两个方向。
· 六计划读数的口径：`released` 是「行真的执行了」的那个数（`3961aa2bf` 之后才可信），
  `balanced` 不是 —— 计划按自己写下的行算平衡，写出了一行没有后端执行也读平衡。
  `box_of_a_round` 的 `missing=0` 说明锚点看见的盒子计划都认，**错的不是锚点，是行**。
· 量它的成本：一条探针 + 一次 `test/plans/probe/refleak.plan.toml`（四后端，约 90 秒）。
  ⇒ 下一个想知道「一轮一个值到底怎么数」的人，不必再从注释开始猜。
```
