# 文档注释后面空一行，它还是文档注释吗？（`frontend.format_keeps_ast` 那一条红）

一条快层红卡在一个语义判断上，施工方**没动任何文件**，请你定：

- 21 个用例文件写的是"**doc 注释 + 空行 + 声明**"这种形状；格式化（`frontend.format_keeps_ast` 那条检查）会把注释**并到声明上**，于是 AST 变了；把那个空行删掉（例如 `tags/decl.cml`）就稳定。
- 两种可能，你不定我们不知道改哪边：
  1. **解析器的问题**：文档注释归属不应由空行决定 ⇒ 有无空行 AST 都该一样，那要改解析器/格式化器；
  2. **用例的问题**：空行就表示"这不是文档注释、只是普通注释" ⇒ 那 21 个文件的形状本身写错了，要挪掉空行（**会连带移动行号**）。
- 额外约束：这 21 个里有 **2 个是 `native_declarations` 的输入**，而那一组是你裁定过要**保持红**的（施工方线上按裁定留红），所以无论你怎么定，这 2 个都要单独处理。
