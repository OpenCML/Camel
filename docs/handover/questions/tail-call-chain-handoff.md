# 尾调用的链交接：被拼接体的链该接到哪里

## 问题

`internal` 的内联在把一张体接进调用点时，被拼接体的语句链要接到调用者那条链上的某个位置。调用之后还有语句时，这个位置是"调用之后的第一条语句"，现状代码接得上。**当调用就是块的最后一条语句时（尾调用），接不上**：被拼接体的链整段从图的出口不可达，于是块里的效应（打印）虽然还在图里，却永远不运行。

## 我量到的

在 `sync` 块里写 `return 1 + countdown(n - 1)`，`countdown` 是递归函数、体内带打印，经 `std::opt` 展开后行为差异是"三行 `tick` 打印丢失"。插桩统计了每一次拼接（`splice=` 是调用节点 id）：

| 拼接 | 体自带链 | 调用前驱 | 调用后继 | 交接段是否执行 |
| --- | --- | --- | --- | --- |
| `14` | 是 | 1 | 1 | 是（交接到 38，成功） |
| `15` / `30` / `31` / `47` / `48` | 是 | 1 | **0** | **否** |

- 六次带链体的拼接里，只有第一次有后继，其余五次**都是尾调用**：调用就是块的最后一条语句，块里没有"调用之后的语句"可以承接。
- 交接段的后继清单来自调用的 sync 后继与控制后继；后继为空时，段内两处写入都没有对象可写，链就此悬空（实测被拼接体链尾没有任何后继，其前的打印节点仍在图里但从出口不可达）。
- 这条链的悬空发生在内联引擎里，不在其后任何一趟：`fold`、`cse`、`algebra`、`dce` 与收尾的 `order`（减序 + 减控）之后，打印数与"从出口可达的打印数"始终相等；只有下一轮内联之后，两者从 `7==7` 变成 `4==7`。

## 现状代码的三条相关事实

- 调用"有没有链位"的判定只认 sync 前驱、sync 后继与 order 前驱（`src/runtime/draft_inline.cpp#callHasChainPlace`）。
- 体自带链时的交接口以"调用的 sync 前驱清单非空"为门槛（`src/runtime/draft_inline.cpp#inlineCallableInDraft` 中的 `bodyHasChain` 段）。尾调用处这条清单为空，交接整段不执行。
- 同一处的注释自陈"今天的语料把链写成 control 边，因此没有链位可交接"（`src/runtime/draft_inline.cpp`）。**这条前提在链改写成 sync 边之后已经不再成立**：现在链位由 sync 边承载，而尾调用处只剩 control 侧的前驱，于是两边的判定都对不上。

## 我试过的两条路（都失败，附原因）

1. **造转发门 + 把值的读取改指向它**：在无后继时用一个 GATE 转发块的值，并把该值的读取全部改到这个门上。`std::opt` 单计划从 96 例 95 过掉到 **65 过 / 31 红**（`static_branches`、`recursion_unroll`、`shape_unroll` 的形状与 `.rgir` 断言一起翻面）。原因：无后继是**尾调用的通例**而非罕见情形，这等于给每次尾调用都套一个门并重写整张图的读取。
2. **只在无后继时接"本块唯一的转发门"**：找读该值的 GATE、要求它与调用同块且恰好一个，再把它接到体尾。实测：`normUsersOf(值)` 里**没有**同块的 GATE，条件一次都没成立，图没有任何变化，行为差异仍在。

## 一次真实测量到的副作用

把控制侧后继改接到体尾（把交接的后继清单取成"控制后继 ∪ sync 后继"），行为差异没修掉，**但形状变了**：`exemplars/05_effect_order/expected/simplified.agir.dot` 的第 297 行记录的是一条 NORM 边，实跑得到的是体尾键出的一条 SYNC 边。也就是说这条改动**不是行为中性的**，而记录不许重录，所以它没有落地（现存在实验分支上，作为起点）。

## 相邻的一条，避免重复排查

`control_data_paths` 那条例（保留了一条数据已覆盖的 control 边）与本文**不同源**：同一套探针在它上面全程打印数等于可达打印数、没有任何链断；它是"减少控制依赖"没有把数据已覆盖的 control 判掉，属于另一处。

## 要问的一句

**块的最后一条语句是调用时（尾调用），被拼接体的链应当接到哪里——块的值门、块的 exit、还是调用所在块那条链的后继？**

我们试过前两种：接值门会让形状大面积翻面（尾调用是通例，等于每次内联都套一个门）；找不到同块值门时，那段代码一次都不执行。
