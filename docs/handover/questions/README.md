# 待裁问题（一问一页）

作者每轮先读这里。**一页只放一个问题**，每页三段：**现象**（实测/读码得到的事实，带 `file:line`）、
**两条路的代价**、**我方默认建议**（没裁定前按它做，并写明按它做会留下什么限制）。

放这里的是"猜不得"的事：两种写法语义不同、或一种要动语义/类型系统，不能由施工方 ad hoc 定
（`docs/design-principles.cn.md`：未决问题归语言作者）。已经能按现有裁定推进的事不进这里。

裁完的页把结论写到页首的 `裁定：` 一行，并在同一提交里把默认建议改写成"已按裁定落地"，
不要删页——下一个人要知道这条路为什么长这样。
