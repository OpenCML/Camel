# 待裁索引：谁在等作者，堵着什么

> **一页一问。这个目录只放还在等回答的页；作者读过的页整体挪进 `../reviews/`，所以 `questions/` 空不是没人在问，是问题都被读过了。**

> **本文件不再逐页列表。** 目录里有什么页，就是还在等什么；每页开头三行写清「问什么 / 堵着谁 / 我没能自己定的理由」。已裁的页在 `../reviews/`，按裁定日期留档。

## 现在的状态

每页的状态（待裁 / 已裁未落 / 已裁已落）与它今天堵着的具体工作，写在当天那份交接报告里（`docs/handover/reports/`）。索引按「堵住多少工作」排序，因为作者的时间应该花在最贵的那页上。

## 落页的规矩

- **只在真有工作被它堵住时成页**；其余未决留在设计原则里，等它真的挡住一条车道再成页。
- **一页一问**：不要把两件事写进同一页，作者只能答一个。
- **页落进这个目录之后，不要再来改本文件**——页本身就是索引，改它只会让下一次合并多一处冲突。
