| 程序 | c=true | c=false | 结论 |
|---|---|---|---|

| B `x = if c then 1 else 0` | **语法错** `UnexpectedToken: Unexpected 'if'` | 同 | 赋值右边必须加括号 |

## 判断：改写就够，不必造节点

`D` 在未改动的基线上就打印 `1 / 7`，说明 **JOIN + 每臂 GATE + `BRCH` 按条件选值这套机器已经存在**，
而且选得对。于是第 ②a 步的做法是：

**把语句形分支改写成带值的赋值**——`if c then { x = 1 }` ⇒ `x = (if c then 1 else x)`；
写的那条臂取臂的值，没写的那条臂取"分支之前的版本"。只对"唯一被写、且写在语句形分支臂里"的
`var` 生效。注意 **B 说明赋值右边必须括号**，改写时不能省。

`C` 在基线上本来就对（`1 / 7`），所以改写是**保语义**的：把已经有正确语义、但保留着单元的
形状，换成语义相同、图上没有单元的形状——这正好是"`var` 是 SSA 名字"要的那一步。

## 顺带纠正一条前几轮的说法

之前几轮把 `q1` 的 `0 / 0` 记成"语句形分支的 JOIN 不选值"。真正的读法是：
**基线的语句形分支是对的**（C 打印 `1 / 7`），`0 / 0` 是我把 `int` 塞进它 WITH 槽之后的行为。
"语句形 JOIN 不选值"这个结论仍然成立（它对 void 语义没变），但它不该被用来解释基线的正确性。
