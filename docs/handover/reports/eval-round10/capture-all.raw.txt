# build=714cf0d93
# `edits-ecoop.cml` is copied into the scratch root as `eco.cml`: a module's name is its file's
# stem, so a pass library reaches a command under that name. The file in the tree is not renamed
# and not edited. The program is the six writings' baseline.
#   print_unordered  a print spliced at a pure node of main -- expected refused (order check)
#   print_ordered    the same body spliced at a statement of the chain -- expected accepted, and
#                    the announcement takes that line's place, so main still prints three lines
#   print_appended   the same body at the same pure node as print_unordered, then ordered *after*
#                    the third print -- expected accepted, and main prints four lines (the
#                    additive form the take-over row above cannot show)
#   print_appended_reversed  the same edge anchored at the third print instead -- refused: the
#                    line lands between two prints and nothing orders it against the earlier one
#   print_prepended  the same splice ordered *before* the first print of the chain -- expected
#                    accepted, with the new line first (the reverse edge anchored where it can
#                    be complete: against the head, not against the third)
#   loss_print       the same print in loss, whose body has no call the analysis cannot name --
#                    expected refused (effect check, PassEffectBeyondType)
#   drop_print       every println erased -- expected accepted, and nothing printed
#   break_rate       the targets tensor put in the learning-rate slot -- expected refused by the
#                    check on the edge's types
# The break_rate row selects the one constant of type float and the one of type f32[4, 1]; a row
# whose selection is not one node now REFUSES and names the count, instead of returning the
# program unchanged -- a no-op printed the program's own output where a refusal belonged, and the
# record could not tell a rewrite that declined to pick from a pass that never ran. The same rule
# fixed the weight print's selector: it was `type_text(...) == 'f32[...]'`, which held while the
# weight's shape was stated in full and fails once `Linear.weight` is `f32[?, ?]`; it is now
# `shape_text(...) != null`, "the operand is an array of known element type", and the three
# rewrites anchored on that print stopped being no-ops on 2026-11-20.
