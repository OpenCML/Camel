# D 类 4 条：改写成什么断言，为什么等价

对象：`docs/handover/m4-autodiff-case-classes.cn.md` 的 D 类（4 条，机制特定、新路线无对应物）。
每条要能落到**一条可写的新断言**上——没有等价性质的，不是“消失”，是“漏了”。

三个数：**改写 2 条 / 移出 M4 1 条 / 随实现消失 1 条**（2 + 1 + 1 = 4）。

## 1. `collapse.cml` —— 改写（同类比较换对照物）

**现断言**：`grad` 的图经过内联与化简后“塌成直线代码”，值等于 `h'(x) = 2x + 6(x + 1)`；
对照物是 **pullback 形式**（每次调用一对 `(value, pullback)`、回传是闭包）。

**为什么不能照搬**：`pullback` 这个对照物在新路线里不存在（输出图里没有回传闭包，设计原则 6.x）。

**改写成什么**：同一条数值断言不变（`h'(2) = 2·2 + 6·3 = 22`），把“与 pullback 形式同值”换成
“**与 `vjp` 形式同值**”：`grad(h)(2)` 与 `transpose(split(reinterp<jvp>(h)))` 给出的值逐位相同。

**为什么等价**：两句话断言的是同一个函数的两条实现路径给出同一个数；换的只是路径的名字，
不换被数的那个数。

## 2. `second_order.cml` —— 改写（恒真断言换掉）

**现断言**：二阶梯度图**化简后没有直接调用也没有间接调用**（`f''(2) = 12`、`grad(h)` 逐元素 `6x`），
即“图里没有调用”这条形状断言。

**为什么不能照搬**：新路线里 `transpose` 产出的图**本来就没有调用**（结构在建图期展开），
这条形状断言会**退化成恒真**——看着还在守，其实什么都守不住。

**改写成什么**：把形状断言换成**结构断言**：二阶梯度图里**没有 `:#op/vjp` 或 `#op/jvp` 标记之外的
残留变换**，且**残差数量为 0**（二阶不需要保留一阶的残差，因为一阶的残差是常量级），
数值断言（`f''(2) = 12`、`6x`）原样保留。

**为什么等价**：原断言想钉的是“二阶不留下运行期结构”（调用=运行期跳转）；新断言钉的是
“二阶不留下一阶才需要的残差”。两者都是“二阶的图是纯数据流”的另一种写法，且新断言
**不会自动成立**：留了残差就是红。

## 3. `fused_grad_check.cml` —— 移出 M4

**现断言**：`tensor::fuse` 标出的组（matmul + add + relu）里，每组的梯度与有限差分一致；
即“融合分组不改变可求导的算子集合”。

**为什么不归 M4**：它检查的是**融合分组**（`tensor.fusion` 属性与组内算子集合），求导只是
借来当探针。这条线的归属是 **tensor 融合那条线**（`modules/tensor/passes/fuse.cpp` 那一族，
72 小时计划里没有单列，挂在 tensor 板上）。

**移出后写什么**：在 tensor 线的计划里保住这条用例，断言不变（组内算子集合 + 梯度对有限差分）；
**在 M4 的账上不记它**。

**为什么等价**：它本来就不是“库层能不能过”的问题——移到 tensor 线之后，它守的东西一个不少。

## 4. `pb_statics_gc.cml` —— 随实现消失（等价性质迁到 transforms 的图上）

**现断言**：运行期构造的 pullback 子图，其静态常量（`permute_inverse` 的置换数组）在 GC 后仍活着；
在 GC stress 下不崩。

**为什么消失**：它钉的是 `pullback.cpp` 建出来的子图——那个机制随 `pullback.cpp` 一起退役。

**等价性质（新断言，写在 transforms 的图上）**：`transforms` 建出的变换图，其静态常量
（置换/形状数组）在**收集之后仍可达**：跑一次 `with_grad` 的等价值（库层 `grad`）在
`--gc-stress safepoint=1` 下不崩，且**图的静态常量计数在收集前后不变**。

**为什么等价**：原断言钉的是“静态常量有根”；新断言钉的是同一件事，只是对象从 pullback 子图
换成变换图。这不是换个名字——变换图确实有自己的一组静态常量（规则实例化时的常量），
没有根一样会崩。

## 判据

「退化成恒真的断言要换掉，不是留着——恒真的断言比没有断言更坏，它看起来还在守。」

## 边界

只写表，未改 `modules/autodiff`；移出 M4 的那条写明归 tensor 融合那条线。
