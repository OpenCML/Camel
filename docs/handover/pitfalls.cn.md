# 踩过的坑（症状 / 为什么 / 怎么避免）

每个生成器、每条守卫都有一条"看起来修好了、其实把红推给了下一层"的路。这张表只记实测过的，
每条都附当时的读数。一条三行：症状 / 为什么 / 怎么避免。没有读数的不要写进来，"感觉容易错"不是坑。

| 症状 | 为什么 | 怎么避免 |
