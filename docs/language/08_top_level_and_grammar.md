# 8. 程序与文法

[English](en/08_top_level_and_grammar.md) | 中文

本章描述程序的顶层结构，给出文法概要，并汇总文法接受但尚未实现的写法。完整的文法在 [8.5](#85-完整文法)，它由解析器源码生成。

---

## 8.1 程序

```
program : (decl ';'?)* EOF
decl    : moduleDecl | importDecl | exportDecl | namespaceDecl | usingNamespaceDecl
        | dataDecl | funcDecl | typeDecl
```

模块顶层只有声明，没有可执行语句；执行从 `main` 开始（[4.1](04_execution_model.md#41-程序与入口)）。

| 声明 | 文法 | 章节 |
|---|---|---|
| 模块 | `module 名字` | [5.1](05_modules.md#51-模块声明) |
| 导入 | `import (模块 \| (名字 \| { 名字 (as 新名)?, ... }) from 模块)` | [5.2](05_modules.md#52-导入) |
| 导出 | `export (dataDecl \| typeDecl \| { 名字, ... })`；函数的 `export` 写在 `func` 前 | [5.3](05_modules.md#53-导出) |
| 命名空间 | `namespace 限定名 { ... }` | [5.4](05_modules.md#54-命名空间) |
| 展开命名空间 | `using namespace 限定名` | [5.2](05_modules.md#52-导入) |
| 数据 | `(let \| var) 名字 (: 类型)? = 表达式` | [7.2](07_statements.md#72-let-与-var) |
| 函数 | `标注* (with <形参>)? export? 修饰符* func 名字(形参) (: 类型)? 块` | [7.4](07_statements.md#74-函数) |
| 类型 | `type 名字 (<参数, ...>)? = 类型` | [7.7](07_statements.md#77-类型声明) |

## 8.2 语句与块

```
stmt      : dataDecl | funcDecl | typeDecl | dataExpr | usingNamespaceDecl | retStmt | blockStmt
retStmt   : (return | throw) dataList
stmtBlock : sync? '{' (stmt ';'?)* '}'      // 语句以换行或 ';' 结束，见 2.1
blockExpr : stmtBlock | dataExpr            // 分支臂、lambda 体
```

## 8.3 表达式

从低优先级到高优先级（见 [6.12](06_expressions.md#612-运算符优先级)）：

```
dataExpr   : waitExpr | ctrlExpr
ctrlExpr   : if logicalOr then blockExpr (else blockExpr)?
           | match 名字 '{' (case pattern ('|' pattern)* '=>' blockExpr)+ '}'
waitExpr   : wait? assignExpr
assignExpr : logicalOr (('=' | '+=' | '-=' | '*=' | '/=' | '%=' | '^=' | '@=' | '&=' | '|=') logicalOr)?
logicalOr  : logicalAnd ('||' logicalAnd)*
logicalAnd : or ('&&' or)*
or         : and ('|' and)*
and        : equality ('&' equality)*
equality   : relational (('===' | '!==' | '==' | '!=') relational)*
relational : additive (('<' | '>' | '<=' | '>=') additive)*
additive   : multiplicative (('+' | '-') multiplicative)*
multiplicative : power (('*' | '/' | '@' | '%') power)*
power      : nullable ('^' power)?
nullable   : unary (('??' | '!!') dataExpr)?
unary      : link (as 类型)?
link       : neg (('->' | '?->') comp)*
neg        : ('-' | '!' | '~') negPower | comp
negPower   : ('-' | '!' | '~') negPower | comp ('^' negPower)?
comp       : anno ('..' anno)*
anno       : primary ( '.'字段 | '[' 下标 ']' | '(' 实参 ')' | '<' with 实参 '>' )*
primary    : 名字 | 字面量 | '[' 元素, ... ']' | '{' 键: 值, ... '}' | '(' 表达式, ... ')' | lambda
lambda     : 修饰符* ('<' 形参 '>')? '(' 形参 ')' (':' 类型)? '=>' blockExpr
pattern    : 字面量 | '_' | null | error 名字 | 名字
```

下标、实参与 `with` 实参必须紧贴它前面的表达式。`(e)` 是括号表达式，`(e,)` 是单元素元组。

## 8.4 类型

```
typeDecl  : 'type' 名字 ('<' 参数, ... '>')? '=' (类型 | enumBody)
typeExpr  : arrayType ('?' | '!')*
arrayType : specType ('[' ']')*
specType  : primaryType ('<' (类型 | const 数据), ... '>')?
primaryType : 名字 | '(' 类型 ')' | '(' 类型, ... ')' | '{' 名字: 类型, ... '}'
            | 修饰符* '(' 形参 ')' '=>' 类型 | typeas 名字
enumBody  : 'enum' '{' 变体, ... '}'
变体      : 名字 | 名字 '(' 类型, ... ')' | 名字 '{' 名字: 类型, ... '}'
```

- `T?`、`T!`：[3.4](03_data_model.md#34-可能为空-t-与可能出错-t)。
- `typeas T`：[7.5](07_statements.md#75-泛型函数)。
- `constas n`：两种用法，都是编译期的名字（[设计原则 5.4](../design-principles.cn.md)）：在 `const` 实参里给维度命名——名字在形参类型里第一次出现时用 `constas` 绑定，之后直接写 `n`；或者作为函数声明的一个**值形参**（`func f(constas n: int, ...)`），由调用点的常量绑定（[7.5](07_statements.md#75-泛型函数)）。值形参可以写在形参表的任意位置，个数不限；每个值各自进入实例键。
- `enum`：[3.5](03_data_model.md#35-枚举-enum)。
- 尖括号：类型函数的实参（[7.7](07_statements.md#77-类型声明)）或模块类型的实参。

## 8.5 完整文法

下面是语言的全部产生式，与解析器逐条对应：每条产生式写在实现它的函数上方（`src/parse/syntax/parser*.cpp`），本节由 `node scripts/check-grammar.mjs --write` 从那里生成，测试 `grammar.reference_in_step` 保证两边一致。记法：`'x'` 是字面记号，`IDENTIFIER`、`INTEGER`、`REAL`、`STRING`、`MULTI_STR`、`FSTRING` 是记号类（见[第 2 章](02_lexical.md)），`OPERATOR` 是任一运算符记号（只用于 `operatorName`，其中的 `IDENTIFIER` 是名字 `operator`；`ruleDecl` 里的两个 `IDENTIFIER` 是名字 `rule` 与 `when`，`analysisDecl`/`analysisClause` 里的 `IDENTIFIER` 是名字 `analysis`、`initial`、`join`、`widen`、`on`，只在那里有特别的含义），`SEP` 是 `;`，`*` `+` `?` `|` 与括号是通常的含义。

文法之外的两条排版规则（[2.1](02_lexical.md#21-行空白与分隔)）决定产生式在哪里适用：

- `annoExpr` 里的 `indices`、`parentArgues`、`angledValues` 与后缀 `!`，以及 `specType` 的 `<`，必须紧贴前一个记号；`relationalExpr` 的 `<` 前面有空白。在尖括号表内，紧贴前一记号或位于行首的 `>` 闭合它。
- 表达式不越过换行继续，除非换行后的运算符只能是二元的；圆括号、方括号、尖括号、结构体花括号之内换行没有意义。

有多种读法的地方按下面的规则判定，每一处只看有限个记号：

| 位置 | 判定 |
|---|---|
| `(` 开头：lambda 还是元组／括号表达式 | `(名字:`、`(var`，`(名字)` 或 `(名字, ...)` 且其后是 `=>`、`:`，或空表后跟 `=>`、`:` 时是 lambda |
| 类型里的 `(` | `(名字:`、`(var`、空表后跟 `=>` 是函数类型；`(T)` 是括号类型；其余是元组类型 |
| `{` 开头：结构体还是块 | `{ 名字 :`、`{ ...` 是结构体；`{}` 作分支臂、lambda 体时是空块，作语句时是空结构体 |
| 实参：位置实参还是具名实参 | 第一个 `名字 :` 起是具名实参 |
| 类型之后的 `+` `-` `^` | 其后能开始一个类型时属于类型（`x as T + U` 是转换为类型 `T + U`） |
| 一元 `-` | 永远是运算符；比 `^` 松、比 `->` 紧；直接作用在数字上时给出负的字面量 |

## 8.6 保留但尚未实现的写法

下列写法文法接受（或关键字已保留），编译器明确拒绝。它们的含义多数尚未决定，不要依赖。

| 写法 | 得到的诊断 | 现在的替代写法 |
|---|---|---|
| 展开 `[...xs, y]`、`{ ...p, x: 1 }`、`f(...args)` | `ConstructNotSupported` | `concat(xs, [y])`；逐个写出字段 |
| `e is T` | `ConstructNotSupported` | 无（运行时没有类型信息） |
| 非空断言 `x!` | `ConstructNotSupported` | `x ?? 默认值`、`match` |
| `f ?.. g` | `ConstructNotSupported` | 无 |
| `f..g` | 组合的结果不能被调用（`ArgumentsMismatch`） | `(x: T) => g(f(x))` |
| `wait { ... }`，以及名字、字面量、lambda 之前的 `wait` | `ConstructNotSupported` | `sync { ... }` |
| `try { } catch e: T { } finally { }` | `SemanticDiag::TryCatchNotInLanguage`（不属于语言） | `T!` 与 `!!`、`?->`、`case error e` |
| 元组模式、结构体模式；对普通类型的标识符模式 | `ConstructNotSupported` | `if` 链；先取成员 |
| 结构体解构 `let { x, y } = p`、数组解构 `let [a, b] = xs` | `SemanticDiag::FeatureNotSupported` | `p.x`、`xs[0]`（元组解构可用） |
| 关键字实参 `f(a: 1)` | `FeatureNotSupported` | 按位置传 |
| 形参默认值 `b: int = 5` | `FeatureNotSupported` | 重载；`with` 形参 |
| 切片下标切的是第一维以外的维度 `xs[:, 0]`、`xs[a:b, c]` | `SemanticDiag::ConstructNotSupported`（诊断里点名 H17） | 先用 `take` 取行，或一次只切一维 |
| 切片下标的步长不是 1 `xs[a:b:s]` | 数组是运行时 `RuntimeDiag::InvalidArgument`，张量是编译期的 `ArgumentsRejected`（都点名 H17） | `xs->slice<0, a, b, s>` |
| 类型运算 `A & B`、`A \ B`、`A + B`、`A - B`、`A ^ B` | `FeatureNotSupported` | 无 |
| `typeof e`、`名字 of T` | `FeatureNotSupported` | 无 |
| `keyof` | 语法错误 | 无 |

此外有一处“能写出来但目前用不了”：带函数类型的声明 `let f: (x: int) => int = g`。
