# 2. 词法

[English](en/02_lexical.md) | 中文

本章描述源码的词法结构。精确的规则在 `antlr/OpenCMLLex.g4`。

---

## 2.1 行、空白与分隔

- 空格、制表符、换行都只是分隔，没有语法含义。语句之间可以换行，也可以用 `;` 分开；一行写多条语句时用 `;`。
- **调用、下标、尖括号实参必须紧贴它前面的表达式**，中间不能有空白：`f(1)`、`xs[0]`、`scale<3>`。`f (1)` 是语法错误，因为 `(1)` 会被当成另一个表达式的开头。
- 换行本身不结束语句：解析器总是尽量把后面的记号并入当前的表达式。上一条语句以 `>` 结尾（`with` 实参）、下一行又以字面量开头时，可能被读成一次比较；下一行自己又带尖括号时，编译器在那个 `>` 处给出警告 `SyntaxDiag::ComparisonAcrossLines`，提示两条语句可能被连成了一条。遇到这种情况在两条语句之间写 `;`，或把下一行写成函数调用的形式（`println(...)`）。
- 源文件按 UTF-8 读取。

```cml
let a = 1; let b = 2
let c = a + b
```

## 2.2 注释

- `//` 到行末是行注释。
- `/* ... */` 是块注释，可以跨行，不能嵌套。
- `#` 到行末也被忽略，所以脚本第一行可以写 `#!/usr/bin/env camel`。

## 2.3 标识符

标识符以字母或下划线开头，后面是字母、数字、下划线：`[a-zA-Z_][a-zA-Z_0-9]*`。区分大小写。单独的 `_` 是 `match` 的通配模式。

引用一个名字时可以带 `::` 限定：`math::sqrt`、`Tensor::ones`（见第 5 章）。

## 2.4 关键字

下列词是保留字，不能当名字用（用了得到 `SyntaxDiag::KeywordAsIdentifier`）：

| 类别 | 关键字 |
|---|---|
| 声明 | `let` `var` `func` `type` `with` `module` `import` `export` `from` `namespace` `using` |
| 控制 | `if` `then` `else` `match` `case` `return` `throw` `wait` `sync` `macro` |
| 类型与转换 | `as` `typeas` `const` |
| 字面量 | `null` `true` `false` |
| 保留，尚未实现 | `is` `use` `enum` `for` `in` `of` `try` `catch` `finally` `raise` `typeof` `keyof` `inner` `outer` `atomic` `shared` |

最后一行的词各自的状态见 [8.6](08_top_level_and_grammar.md#86-保留但尚未实现的写法)。

## 2.5 字面量

### 2.5.1 整数

| 写法 | 例 | 值 |
|---|---|---|
| 十进制 | `0`、`42`、`-7` | |
| 十六进制 | `0xff` | 255 |
| 二进制 | `0b1010` | 10 |
| 八进制（`0` 后跟八进制数字） | `077` | 63 |
| 带指数 | `1e6`、`1e3` | 1000000、1000 |

- 整数字面量的类型是 `int`（64 位有符号），范围 -9223372036854775808 到 9223372036854775807。
- **超出范围的字面量是编译期错误**（`SemanticDiag::LiteralOutOfRange`）：`9223372036854775808`、`1e400`、`0x8000000000000000` 都是。`-9223372036854775808` 在范围内。带类型的声明把字面量放进更窄的类型时同样检查：`let b: i32 = 3000000000`、`let c: f32 = 1.0e39` 是错误。浮点字面量大于 `float` 能表示的最大值（`1.0e400`）也是这个错误。
- **带指数的整数仍是整数**：`1e6` 是 `int`，不是 `float`；负指数向零截断，`1e-2` 是 `0`、`15e-1` 是 `1`，并给出警告 `SemanticDiag::IntegerLiteralTruncated`（结果恰为整数时不警告，如 `1500e-2`）。要浮点数就写小数点：`1.0e-2`。带负指数的字面量应当是浮点数还是错误，尚未裁定。
- 指数只用于十进制：`0b1e5`、`07e2` 是 `SemanticDiag::InvalidLiteral`（十六进制里 `e` 是数字）。
- 没有数字分隔符（`1_000` 是语法错误），没有 `0o` 前缀。
- **数字记号本身不带正负号。** 两个操作数之间的 `+`、`-` 总是二元运算符，与空格无关：`n - 1`、`n-1`、`n -1` 都是减法。在需要操作数的位置上，紧跟着数字的 `-`、`+` 是字面量的符号：`-1`、`+2.5`、`[-1, 2]`、`f(-1)`、`case -1 =>`、`-9223372036854775808`。带符号的字面量是一个操作数，所以 `-2->f` 是把 `-2` 传给 `f`，而 `-a->f` 是 `-(a->f)`（[6.12](06_expressions.md#612-运算符优先级)）。指数里的符号属于数字记号本身：`1.0e-2`。
- 换行不结束语句，所以以 `-` 或 `+` 开头的一行会与上一行的表达式连成一次减法或加法（与以 `-x` 开头的一行相同）；需要分开时写 `;`。

### 2.5.2 浮点数

- 写法是“数字 `.` 数字”，可带指数：`1.0`、`0.5`、`2.5e+3`、`1.0e-2`。小数点两边都必须有数字（`.5`、`5.` 是语法错误）。
- 类型是 `float`（64 位双精度）。字面量的值是离所写的十进制数最近的双精度数（舍入到偶数），与 `float('...')` 对同一段文本给出的值相同。
- 打印时默认保留 6 位有效数字并去掉多余的零：`1.0` 打印为 `1`，`0.1 + 0.2` 打印为 `0.3`，`3.14159265358979` 打印为 `3.14159`。需要别的精度时用 `format`：`'{:.17g}'->format<0.1>` 得到 `0.10000000000000001`。

### 2.5.3 字符串

- 单引号或双引号：`'Hello'`、`"Hello"`，两者等价；一种引号里可以直接写另一种。
- 转义：`\n`、`\t`、`\r`、`\\`、`\'`、`\"`、`\xHH`。
- 三个引号的多行字符串：`'''...'''` 或 `"""..."""`，中间可以换行。
- 字符串是字节序列。`len` 给出字节数：`len('héllo')` 是 6，`len('中文')` 是 6。
- 反引号的格式化字符串 `` `...` `` 保留，尚未实现（`SemanticDiag::ConstructNotSupported`）；用 `format`：

```cml
println('{} + {} = {}'->format<1, 2, 1 + 2>)
println(format<3.14159>('pi is about {:.2f}'))
```

```text
1 + 2 = 3
pi is about 3.14
```

### 2.5.4 布尔与空值

`true`、`false` 的类型是 `bool`。`null` 是每个可空类型 `T?` 的空值（见 [3.4](03_data_model.md#34-可能为空-t-与可能出错-t)）。

## 2.6 运算符与分隔符

| 记号 | 用途 |
|---|---|
| `+` `-` `*` `/` `%` `^` `@` | 算术：加、减、乘、除、取余、乘方、矩阵乘 |
| `==` `!=` `<` `>` `<=` `>=` | 比较 |
| `===` `!==` | 同一性比较 |
| `&&` `\|\|` `!` | 逻辑与、或、非 |
| `~` | 按位取反 |
| `=` `+=` `-=` `*=` `/=` `%=` `^=` `@=` `&=` `\|=` | 赋值与复合赋值 |
| `??` `!!` `?->` | 拆开可空值、拆开可能出错的值、出错则传递 |
| `->` | 管道：把左边的值作为右边函数的实参 |
| `..` `?..` | 函数组合（见 [6.5](06_expressions.md#65-管道)） |
| `.` | 字段与元组成员访问 |
| `::` | 限定名 |
| `=>` | lambda 与函数类型、`case` 的箭头 |
| `?` `!`（类型之后） | `T?` 可能为空，`T!` 可能出错 |
| `@`（函数声明之前） | 标注，见 [7.6](07_statements.md#76-标注) |
| `( )` `[ ]` `{ }` `< >` | 分组、元组与实参；数组与下标；结构体与块；`with` 实参与类型实参 |
| `,` `:` `;` | 分隔 |

各运算符的含义与优先级见第 6 章。注意 `!=` 是一个记号：`let x: int! = v` 里 `!` 与 `=` 之间必须有空格。
