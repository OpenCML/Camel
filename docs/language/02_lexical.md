# 2. 词法

[English](en/02_lexical.md) | 中文

本章描述源码的词法结构。记号表在 `include/camel/parse/syntax/token_kinds.def`，词法分析器在 `src/parse/syntax/lexer.cpp`。

---

## 2.1 行、空白与分隔

- 空格与制表符只是分隔。**换行结束一条语句**，除非这一行明显没有写完：
  - 圆括号、方括号、尖括号实参表、结构体字面量的花括号还没有闭合；
  - 行尾是二元运算符、`,`、`=`、`=>`、`->`、`:`、`then`、`else`、`return` 这类“后面必须还有东西”的记号；
  - 下一行以**只能是二元**的运算符开头：`->` `?->` `.` `..` `?..` `??` `!!` `*` `/` `%` `^` `&` `|` `&&` `||` `==` `!=` `===` `!==` `<` `>` `<=` `>=` `as` `is`，以及赋值运算符；类型里还有 `\`。**有两种身份的符号（`+`、`-`、`@`）出现在行首时，取开始新东西的那种身份**：`-x` 是一条新语句，`@name` 是一个注解。续行时把它留在上一行末尾（矩阵乘 `a @` 换行 `b`）。
  - 下一行是同一个构造的后续部分：`else`、`then`、`catch`、`finally`、`=>`、`from`。

  下一行以 `-`、`+`、`!`、`~`、`@`、`(`、`[`、`{`、名字、字面量或语句关键字开头时，它是一条**新语句**。所以要把一个加减法写成两行，把运算符留在上一行的末尾（`a +` 换行 `b`）；以 `+` 开头的一行不是语句，得到 `SyntaxDiag::LineStartsWithOperator`。
- 分号仍可用来在一行里分隔多条语句。同一行上的两条语句之间也可以什么都不写（前一条在它的表达式无法继续的地方结束），但写 `;` 更清楚。
- **调用、下标、尖括号实参必须紧贴它前面的表达式**，中间不能有空白：`f(1)`、`xs[0]`、`scale<3>`。`f (1)` 是 `f` 与 `(1)` 两个表达式。
- **尖括号与比较。** 紧贴在名字、字面量、`)`、`]`、`}`、`>` 之后的 `<` 开始一个尖括号实参表；其余的 `<` 是小于号。所以**比较运算符 `<` 前面要有空格**：`i < n`。`i<n` 被读成“`i` 带尖括号实参”，随后解析失败，得到 `SyntaxDiag::ComparisonNeedsSpace`。`<=` 总是比较（`<=>` 是规则声明的双向箭头，见 [8](08_top_level_and_grammar.md)）。在尖括号实参表里（不在其中的括号或块里），紧贴前一个记号、或位于行首的 `>` 闭合这个表；空格之后的 `>` 是大于号，因此 `xs->filter<(x: int): bool => x > 1>` 按写出来的样子读，`a<b<c>>` 连续闭合两层。把闭合的 `>` 写在空格后面（`f<a, b >`）得到 `SyntaxDiag::AngleCloseAfterSpace`。尖括号之外，`>` 有没有空格都是比较。
- 源文件按 UTF-8 读取。

```cml
let a = 1; let b = 2
let c = a + b
```

## 2.2 注释

- `//` 到行末是行注释。
- **`///` 开头的行是文档注释**：紧挨在一个声明（`func`、`let`/`var`、`type`，含它前面的标注、`with`、`export`）正上方、连续的 `///` 行是这个声明的文档，中间不能有空行。编辑器的悬停显示它，`camel inspect --ast` 把它列在声明上，格式化器保持它的位置。`////` 开头的是普通注释。
- `/* ... */` 是块注释，可以跨行，不能嵌套。
- 文件第一行的 `#!` 到行末也被忽略，所以脚本第一行可以写 `#!/usr/bin/env camel`。除此之外 `#` 不是注释，它开始一个标签（[4.1 的设计原则](../design-principles.cn.md)，见 [8.1](08_top_level_and_grammar.md)）。

## 2.3 标识符

标识符以字母或下划线开头，后面是字母、数字、下划线：`[a-zA-Z_][a-zA-Z_0-9]*`。区分大小写。单独的 `_` 不是名字：它是 `match` 的通配模式；在 `let _ = e` 里表示有意丢弃 `e` 的值（[7.2](07_statements.md#72-let-与-var)）。

引用一个名字时可以带 `::` 限定：`math::sqrt`、`Tensor::ones`（见第 5 章）。

## 2.4 关键字

下列词是保留字，不能当名字用（用了得到 `SyntaxDiag::KeywordAsIdentifier`）：

| 类别 | 关键字 |
|---|---|
| 声明 | `let` `var` `func` `type` `with` `module` `import` `export` `from` `namespace` `using` |
| 控制 | `if` `then` `else` `match` `case` `return` `throw` `wait` `sync` `loop` `while` `do` `for` `in` `static` |
| 类型与转换 | `as` `typeas` `const` `constas` `enum` |
| 字面量 | `null` `true` `false` |
| 保留，尚未实现 | `is` `of` `try` `catch` `finally` `typeof` `keyof` |

最后一行的词各自的状态见 [8.6](08_top_level_and_grammar.md#86-保留但尚未实现的写法)。

形如 `__x__`（前后各两个下划线）的名字是编译器自己用的：运算符就是这样命名的函数（`a + b` 是 `__add__(a, b)`）。变量、形参、函数都不能取这样的名字（`SemanticDiag::ReservedIdentifier`）。程序要给自己的类型定义运算符，写 `func operator +(a: V, b: V): V`（[7.4.5](07_statements.md#745-运算符重载)）；`operator` 不是关键字，只有紧跟在 `func` 之后、后面是一个运算符时才是这种写法。

## 2.5 字面量

### 2.5.1 整数

| 写法 | 例 | 值 |
|---|---|---|
| 十进制 | `0`、`42`、`-7` | |
| 十六进制 | `0xff` | 255 |
| 二进制 | `0b1010` | 10 |
| 八进制（`0o` 后跟八进制数字） | `0o77` | 63 |

- 整数字面量的默认类型是 `int`（64 位有符号），范围 -9223372036854775808 到 9223372036854775807。上下文要求别的整数类型时它取那个类型（[3.2](03_data_model.md#32-数值)）：`let b: i32 = 1` 里的 `1` 是 `i32`，`f(1)` 在 `f(x: f32)` 里是 `f32`。
- **超出范围的字面量是编译期错误**（`SemanticDiag::LiteralNotRepresentable`，消息引用写下的源码并给出原因，例如 `out of range (-9223372036854775808 to 9223372036854775807)`）：`9223372036854775808`、`1e400`、`0x8000000000000000` 都是。`-9223372036854775808` 在范围内。带类型的声明把字面量放进更窄的类型时同样检查：`let b: i32 = 3000000000`、`let c: f32 = 1.0e39` 是错误。浮点字面量大于 `float` 能表示的最大值（`1.0e400`）也是这个错误；**非零的实数太小、舍入后为零时同样放不进类型**（`1e-9999`，或 `let c: f32 = 1e-50`），原因是“最近的值是零”，不把它读成 0。字面量之间的运算按精确值算完再放进类型，所以 `9223372036854775807 + 1` 也是这个错误（运行时的加法则是回绕）；折叠出来的值放不进类型时，位置指向**整个表达式**，不是最后一个操作数。小数放进整数类型（`let x: int = 1.9`）是同一个错误，原因是会被截断。
- **带指数或小数点的字面量，默认类型是浮点数**（[2.5.2](#252-浮点数)）：没有上下文时 `1e6` 是 `float`，值 `1000000.0`，`1e-2` 是 `0.01`；上下文要求 `f32` 时它取 `f32`。整数字面量只有上表的四种写法。
- **以 `0` 开头、后面还跟数字的十进制写法不是数字记号**：`09`、`077` 是词法错误（`LexicalDiag::InvalidNumberFormat`，位置覆盖整个写下的数字串），不会悄悄切成 `0` 与 `9`。八进制写 `0o77`；`0o` 后面必须是八进制数字。有小数点的写法（`077.5`）按浮点数读，前导零不构成歧义。
- 指数只用于十进制：`0b1e5` 是 `SemanticDiag::InvalidLiteral`（十六进制里 `e` 是数字）；`07e2` 是上面的词法错误。
- 没有数字分隔符（`1_000` 是语法错误）。
- **数字记号本身不带正负号，负号永远是运算符。** 两个操作数之间的 `+`、`-` 总是二元运算符，与空格无关：`n - 1`、`n-1`、`n -1` 都是减法。在需要操作数的位置上（前面不是一个值）`-` 是一元负号，对字面量与对名字的读法完全一样：它比 `^` 结合得松，比 `->` 和其余二元运算符结合得紧（[6.12](06_expressions.md#612-运算符优先级)）。`-2 ^ 2` 是 `-(2 ^ 2)`，即 `-4`；`-2->f` 是 `(-2)->f`；`-x->f` 是 `(-x)->f`。直接作用在数字上的负号给出负的字面量，所以 `-1`、`-2.5`、`[-1, 2]`、`f(-1)`、`-9223372036854775808`、`let b: i32 = -2147483648` 照常可写；`match` 的模式里可以写 `case -1 =>`。数字前的 `+` 读作符号（`+2.5`）。指数里的符号属于数字记号本身：`1.0e-2`。
- 换行结束语句（[2.1](#21-行空白与分隔)），所以以 `-x` 或 `-1` 开头的一行是一条新语句，不与上一行连成减法。

### 2.5.2 浮点数

- 写法是“数字 `.` 数字”，可带指数（`1.0`、`0.5`、`2.5e+3`、`1.0e-2`），或十进制数字直接带指数（`1e6`、`1E5`、`1e-2`）。小数点两边都必须有数字（`.5`、`5.` 是语法错误）。
- 默认类型是 `float`（64 位双精度）；上下文要求 `f32` 时它是 `f32`（[3.2](03_data_model.md#32-数值)）。字面量的值是离所写的十进制数最近的双精度数（舍入到偶数），与 `float('...')` 对同一段文本给出的值相同。
- **浮点数转成文字只有一种规则：最短、且读回来得到同一个数。** `println`、`print`、`string(x)`、`format` 的 `{}`，以及数组、元组、结构体、`Map` 里的浮点元素，写出的都是同一段文字：

  | 值 | 文字 | 说明 |
  |---|---|---|
  | `2.0`、`100000.0` | `2.0`、`100000.0` | 整数值的浮点数保留 `.0`，读回来仍是浮点数 |
  | `let a = 0.1; a + 0.2`、`1.0 / 3.0` | `0.30000000000000004`、`0.3333333333333333` | 不再截到 6 位有效数字。字面量之间的 `0.1 + 0.2` 在编译期按精确值算，是 `0.3`（设计原则 5.1） |
  | `0.1`、`3.14159265358979` | `0.1`、`3.14159265358979` | 最短的那一个 |
  | `1.0e21`、`1.0e-7` | `1e+21`、`1e-07` | 十进制指数小于 -4 或不小于 16 时用指数写法，指数带符号、至少两位 |
  | `1.0e15`、`0.0001` | `1000000000000000.0`、`0.0001` | 其余用小数写法 |
  | 正零、负零 | `0.0`、`-0.0` | |
  | 无穷、NaN | `inf`、`-inf`、`nan` | NaN 不带符号（不会打印 `-nan`） |

  `f32` 写出的是读回来得到同一个 `f32` 的最短文字（`f32(0.1)` 是 `0.1`）。`float(s)`、`parse_float(s)` 能读回上面每一种文字。需要别的写法时给 `format` 的占位符加上格式说明：`'{:.2f}'->format<2.5>` 是 `2.50`，`'{:.17g}'->format<0.1>` 是 `0.10000000000000001`。

  **数据文本相对字面量有两处补充**（H15i）。入口参数读取整数字面量的全部进制（`0x`、`0b`、`0o`）；转换函数的整数文本是十进制数字（`int('0x10')`、`int('0o77')` 不是整数）。在两处共同的部分之外：

  1. `inf`、`-inf`、`nan`：它们是 `floatText` 打印无穷与 NaN 的形式，程序写出来的值要能读回（源码里用 `math::inf`、`math::nan`，不加字面量）。浮点参数与 `float(s)`、`parse_float(s)` 接受它们；整数参数与 `int(s)`、`parse_int(s)` 的目标是整数，不读它们。NaN 不带符号；`+inf`、`+nan` 的 `+` 是允许的符号。
  2. **前导零的十进制**：`077` 是 77，`09`、`007` 照常读取；入口参数与所有四个转换函数都这样读。源码里这种写法是词法错误，八进制写 `0o77`；数据里没有八进制的前导零写法，`0o77` 在入口参数里仍是 63，在转换函数的整数文本里不是整数。

  除此之外没有补充：实数点两边都要有数字（`.5`、`5.` 不读），没有十六进制浮点，没有 `Infinity`，没有数字分隔符。**一个非零的实数文本舍入后为零时，三处都拒绝，不读成 0**：字面量报 `SemanticDiag::LiteralNotRepresentable`，入口参数与转换函数报故障（转换函数把它归在 `ConversionOutOfRange`，与上溢同一类拒绝）。

  **NaN 不带符号这一条对格式说明同样成立**：`'{:.2f}'`、`'{:>8}'` 对负的 NaN 写出的仍是 `nan`，宽度与精度都不改变这段文字（大写类型字母按 fmt 的规则写 `NAN`，`'{:E}'`）。`{:+}` 是 `+nan`：`+` 是加在那段文字上的符号标志，不是 NaN 的符号。

### 2.5.3 虚数字面量

- 数字后紧接 `i`，且 `i` 后面不是标识符字符，是**虚数字面量**：`4i`、`4.5i`、`1e3i`。`4if` 是 `4` 与 `if`；`0xFFi` 是 `0xFF` 与名字 `i`（十六进制、二进制、八进制写法不带虚数后缀）。
- 它的值是复数：实部为 0，虚部是写下的数。默认类型是 `c128`（双精度复数，设计原则 5.1）；上下文要求 `c64` 时它是 `c64`（两个部分都按 f32 舍入）：`let z: c64 = 2i` 里的 `2i` 是 `c64`。
- 负号仍是运算符：`-2i` 是 `-(2i)`，实部 0、虚部 -2，打印为 `0-2i`。
- 虚数字面量之间、以及与实数字面量之间按精确值折叠：`(1+2i)*(3+4i)` 是 `-5+10i`。带虚部的字面量表达式默认是 `c128`；把它放进实数类型是 `SemanticDiag::LiteralNotRepresentable`，提示用 `re()`、`im()` 取出实部、虚部。
- 打印规则是 `实部`、`+` 或 `-`、虚部的绝对值、`i`：`3+4i`、`0-2i`、`-1+0i`。整数值的部分不写 `.0`；`c64` 的每个部分用读回来是同一个 `f32` 的最短文字。
- **给复数的格式说明同时写两个部分，与 Python 一样。** 说明的数值部分（符号、`#`、精度、类型字母）分别作用于实部与虚部：`'{:.2f}'` 把 `3+4i` 写成 `3.00+4.00i`，`'{:e}'` 写成 `3.000000e+00+4.000000e+00i`，`'{:#.0f}'` 写成 `3.+4.i`。`+` 或空格符号只写在实部上，虚部的正负是两个部分之间的分隔符，所以 `{:+}` 是 `+3+4i`，`{: .2f}` 是 ` 3.00+4.00i`。布局部分（填充、对齐、宽度）只作用一次，作用于整段文字，默认右对齐：`'{:>12.2f}'` 是 `  3.00+4.00i`，`'{:*>12.2f}'` 是 `**3.00+4.00i`，`'{:^13.2f}'` 是 ` 3.00+4.00i  `。零填充与 `=` 对齐是错误（`SemanticDiag::ArgumentsRejected`），与 Python 一样：`{:08.2f}`、`{:=12.2f}`。类型字母按部分（它们是数）检查，`{:s}` 是错误。没有格式说明的占位符写出上面那段文字（`{}` 对 `3+4i` 是 `3+4i`，不加括号）。**任一部分是 NaN 时，那部分写 `nan`、不写 `-nan`（2.5.2 的同一条规则），带说明与不带说明都一样。**

### 2.5.4 字符串

- 单引号或双引号：`'Hello'`、`"Hello"`，两者等价；一种引号里可以直接写另一种。
- 三个引号的多行字符串：`'''...'''` 或 `"""..."""`，中间可以换行。
- 反引号的**格式化字符串** `` `...` `` 里用 `${表达式}` 插值，`${表达式:格式说明}` 的格式说明与 `format` 的相同（[2.5.4.1](#2541-格式化字符串)）。
- **所有字符串共用一张转义表**：单引号、双引号、三引号与反引号的格式化字符串同表。同一个反斜杠对在哪种字符串里都得到同一个字符，读者不需要先知道自己处在哪种引号里。

| 转义 | 含义 |
|---|---|
| `\n` | 换行 U+000A |
| `\t` | 制表 U+0009 |
| `\r` | 回车 U+000D |
| `\a` | 响铃 U+0007 |
| `\b` | 退格 U+0008 |
| `\f` | 换页 U+000C |
| `\v` | 垂直制表 U+000B |
| `\\` | 反斜杠 |
| `\'` | 单引号 |
| `\"` | 双引号 |
| `` \` `` | 反引号 |
| `\$` | 美元符号 `$` |
| `\0`、`\0oo` | 反斜杠后先写 `0`，再跟 0 到 2 位八进制数字，表示一个字节（0 到 0o77）；`\0` 是空字节，`\012` 是换行 |
| `\xHH` | 1 到 2 位十六进制数字表示的一个字节；没有十六进制数字时原样保留 `\x` |
| `\u{H…}` | 1 到 6 位十六进制数字表示的一个 Unicode 码点，如 `\u{4E2D}` 是“中”；不是合法的码点时原样保留 `\u` |
| 其他 | 原样保留反斜杠与那个字符：`\q` 是 `\q` |

- `\$` 在格式化字符串里也是 `$`。唯一多出来的是 `\${`（美元符号紧跟左花括号）：在格式化字符串里它是表示字面 `${` 的**结构转义**，不开始插值，见 [2.5.4.1](#2541-格式化字符串)；普通字符串与三引号字符串里没有 `${` 这层含义，`\${` 就是字符转义 `\$` 后跟 `{`，同样是 `${`。
- 字符串是字节序列。`len` 给出字节数：`len('héllo')` 是 6，`len('中文')` 是 6。

#### 2.5.4.1 格式化字符串

- 反引号字符串里的 `${` 开始一个**插值**，到与它匹配的 `}` 结束；里面是任意表达式（[6.2](06_expressions.md#62-字面量与构造)）。表达式里可以再出现字符串、注释、花括号和反引号字符串，它们各自成对：`` `point ${({ x: 1 }).x}` ``、`` `${'{'}${'}'}` ``。
- 表达式后面可以写 `:格式说明`，冒号必须在插值的最外层（不在任何括号里）；格式说明与 `format` 的占位符完全一样（`{:5d}`、`{:.2f}`、`{:>8}`）。说明与值的类型不符是编译期错误 `SemanticDiag::ArgumentsRejected`，位置指向那一处插值。
- **普通的 `{`、`}` 是字面字符，不需要转义**：`` `{ }` `` 打印 `{ }`。`${` 只有这两个字符连在一起时才开始插值。
- `\${` 是字面的 `${`，不算插值。它是格式化字符串独有的结构转义（决定 `${` 是否开始插值），不是字符转义；其余反斜杠对都用 [2.5.4](#254-字符串) 的那一张表。所以 `\$` 在格式化字符串里也是 `$`，而 `\${` 与普通字符串里的 `\${` 打印出来都是 `${`。
- 可以跨行，换行原样保留；行内的转义与普通字符串是同一张表（[2.5.4](#254-字符串)），`` \` `` 是字面的反引号（它也不会结束字符串）。
- 插值里没有任何既不是空白也不是注释的记号就是空插值，报 `SyntaxDiag::EmptyInterpolation`：`${}`、`${ }`、`${/*c*/}` 都是，`${/**/ 1}` 不是。它与插值里表达式的普通语法错误分开报告。
- 它可以写成 `'...'->format<...>`，两者是同一棵语法树、同一语义（[6.2](06_expressions.md#62-字面量与构造)）。

```cml
let name = 'Camel'
let n = 42
println(`hello, ${name}!`)                    // 等价于 'hello, {}!'->format<name>
println(`n = ${n}, twice = ${n * 2}`)
println(`pi = ${3.14159:.2f}`)                // 等价于 'pi = {:.2f}'->format<3.14159>
println(`literal { } and \${not} interpolated`)
```

```text
hello, Camel!
n = 42, twice = 84
pi = 3.14
literal { } and ${not} interpolated
```

同一个调用的长写法仍可写：`'{} + {} = {}'->format<1, 2, 1 + 2>`。

### 2.5.4 布尔与空值

`true`、`false` 的类型是 `bool`。`null` 是每个可空类型 `T?` 的空值（见 [3.4](03_data_model.md#34-可能为空-t-与可能出错-t)）。

## 2.6 运算符与分隔符

| 记号 | 用途 |
|---|---|
| `+` `-` `*` `/` `%` `^` `@` | 算术：加、减、乘、除、取余、乘方、矩阵乘 |
| `==` `!=` `<` `>` `<=` `>=` | 比较 |
| `===` `!==` | 保留，暂不支持（编译期错误） |
| `&&` `\|\|` `!` | 逻辑与、或、非；`&&`、`\|\|` 是分支（右侧只在需要时求值），是保留的运算符，不能重载 |
| `&` `\|` | 两边都求值的与、或；普通的运算符，可以重载 |
| `~` | 按位取反 |
| `=` `+=` `-=` `*=` `/=` `%=` `^=` `@=` `&=` `\|=` | 赋值与复合赋值 |
| `??` `!!` `?->` | 拆开可空值、拆开可能出错的值、出错则传递 |
| `->` | 管道：把左边的值作为右边函数的实参 |
| `..` `?..` | 函数组合（见 [6.5](06_expressions.md#65-管道)） |
| `.` | 字段与元组成员访问 |
| `::` | 限定名 |
| `=>` | lambda 与函数类型、`case` 的箭头、规则的单向箭头 |
| `<=>` | 规则的双向箭头 |
| `?` `!`（类型之后） | `T?` 可能为空，`T!` 可能出错 |
| `@`（函数声明之前） | 标注，见 [7.6](07_statements.md#76-标注) |
| `( )` `[ ]` `{ }` `< >` | 分组、元组与实参；数组与下标；结构体与块；`with` 实参与类型实参 |
| `,` `:` `;` | 分隔 |

各运算符的含义与优先级见第 6 章。`<` 与 `>` 既是比较也是尖括号，如何区分见 [2.1](#21-行空白与分隔)。注意 `!=` 是一个记号：`let x: int! = v` 里 `!` 与 `=` 之间必须有空格。
