# Structured row-region lowering (2026-10-16)

Source: `3ba15a22c79b26ec258ab171781b3cdaa5947e72`.

Row regions now lower through the same typed statement representation as other
Tiles kernels. The previous CUDA statement emitter was removed. Shared stage
values, lane trees, exponent bounds, the exact-tree guard, the canonical ascending
fallback and output rounding are explicit in the physical IR. Barriers remain
outside lane-dependent branches and at shared-value lifetime boundaries.

Standard builds and the targeted host/GPU plans passed **87/87 on each GPU**.
Manual Windows checks first exercised row plans, the native verifier and strict
sum bit comparisons. Coverage includes softmax, layernorm, shared producers,
broadcasts, widths 3/33/257/1024, 65537-row grid-stride execution, signed zeros,
subnormals, nonfinite inputs and cancellation requiring the ordered fallback.
No full-project test suite was run.

Three benchmark processes per device used the existing rows suite, which performs
5 warmups and 21 alternating timed samples per implementation. CUDA-event spans
exclude transfer and compilation. On the shared 88 server, device 4 was used for
both an immediate pre-migration baseline (`9191cad0`) and the new revision.
Median optimized device times across the three processes:

| Workload | 3090 before (ms) | 3090 after (ms) | 4060 Ti after (ms) |
|---|---:|---:|---:|
| softmax 128 x 257 | 0.009088 | 0.008608 | 0.019552 |
| softmax 1024 x 1024 | 0.040608 | 0.036928 | 0.051904 |
| layernorm 128 x 257 | 0.021504 | 0.020576 | 0.031552 |
| layernorm 1024 x 1024 | 0.279552 | 0.279552 | 0.198528 |

These measurements show no evident regression in this sample; shared-server
noise and different devices prevent broader performance guarantees. The large
layernorm retains the four-kernel schedule because it exceeds the row policy's
serial-work cap. There is no immediately preceding Windows baseline here.
