# Structured matrix kernels and core semantics (2026-10-16)

## Changes under test

- `6279b06a`: typed physical statement trees for tiled matrix multiplication;
  lexical index/scalar bindings, assignments, predicated typed global/shared
  loads and stores, loops, conditions and block barriers. CUDA is a final printer.
- `0754afb4`: matrix accesses are composed from core indexing instances;
  matrix lowering requires an ascending f32 FMA chain from positive zero.
  Gradient matrix primitives bind their own matmul declaration while retaining
  the gradient declaration as a dependency. Complete index instances are part of
  the process-local source-template key (schema 4).

The consumer validates domain roles/extents, output mapping, reduction law,
coordinate bounds and the independence needed to share panels across outputs.
Unsupported guarded/indirect maps fail explicitly. This is not general lowering
of every core indexed operator. Graph facts and definition graphs are subsequent
integration work.

## Acceptance checks

- Native mutation checks reject out-of-scope or mistyped references, read-only
  stores, zero loop steps and barriers under divergent conditions/loops.
- Core-contract mutations reject out-of-range coordinates, cross-output reads
  incompatible with panel sharing, guarded accesses, false domain constraints,
  absent indexing, non-direct output maps and a non-FMA reduction law.
- A transposed core input map changes the evaluated physical load address and
  generated source, and causes a source-template cache miss.
- GPU matrix cases use M=17, N=19 with K=0,1,15,16,17,34, plus empty M/N.
  All eight CPU/GPU differences must be exactly zero (finite dyadic inputs).
- Cancellation tests retain the residual -2^-46 and the value 1 across two tile
  boundaries, proving the accumulator is not restarted or grouped by panel.
- Existing gradient, mapped fusion, resident data, numeric permission, extrema,
  strict reduction and row fusion regressions remain part of the test selection.

No other GPU workloads were stopped. This batch makes no throughput claim;
its acceptance criteria are structural lowering and unchanged numerical behavior.

The Windows build initially hit the running editor language server's DLL lock;
it completed after stopping that server during artifact synchronization. One
Clang 22.1.0-rc3 optimizer invocation crashed; an unchanged-source standard build
retry completed. The Linux archive checkout reports missing Git metadata during
artifact collection, but the standard build completes with exit status zero.

The statement validator does not claim bounds, race freedom or shared-value
initialization proofs for arbitrary kernels. Those are planner obligations;
the matrix consumer supplies affine bounds checks and a fixed barrier protocol.
Other kernel families still need migration to the statement representation.
