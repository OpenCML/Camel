# Core axis-reduction access maps (2026-10-16)

Source: `1d889a30`.

Axis sum/mean/maximum now validate the declared iteration roles, output
projection and numerical law before scheduling. Serial and parallel-maximum
loads compose the core operand map with physical coordinates. Canonical maps
keep the compact row/axis formula; noncanonical maps cannot use row-region
shared loads. Execution rejects stale row-region plans after such a map change.

Native checks evaluate every address of a transposed 2x2 reduction, verify source
and cache changes, reject out-of-bounds and guarded reads, incompatible output
projections and accumulator laws, and verify rejection of a stale fused row plan.
These synthetic-map checks inspect the physical representation and generated
source; they do not claim GPU execution of an arbitrary custom mapped reducer.
The GPU suite exercises actual registered core operators, strict reduction bits,
row regions, gradients and graph-fact specialization across the VM backends.
