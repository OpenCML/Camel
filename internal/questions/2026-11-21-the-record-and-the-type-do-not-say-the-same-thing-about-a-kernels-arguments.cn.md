# 「规则把切向写在哪个实参上」这件事，被调方的类型说不出

**问句（一句）**：`residualsOf` 走 behind-cut 的晚节点时读 `GCNode::tangentArgs`（`modules/transforms/split.cpp:1594`，`callTangentArgsOf`）来知道「这个调用哪些普通实参是切向」，而 21:29 那条裁定的**理由**说这件事「是被调方提升后的类型已经说了的事」；**实测这两件事在树上读数完全相同（见 §二），但类型在原理上说不出它（见 §三）** —— 这一格是**只把裁定的理由落到它成立的那一格**（`:1558` 的 `ordinary/2` 换成类型读，`:1565` 保留位图），还是**按裁定的字面把 `:1565` 也换成类型读**？

## 默认建议（本轮按此结案）

**只改 `:1558`，`:1565` 保留位图；位图不删（它还有读的人）。** 理由是裁定的理由只在那格成立：那里问的是「这个调用把哪些实参交给了一个**答对**的被调方」，被调方自己的提升签名就是答案；`:1565` 问的是「规则把切向写在**它自己那条右式的第几个位置**上」，被调方的签名从来说不到这句话。

## 一、裁定的字面点了两处，理由只覆盖一处

裁定原文（`internal/reviews/questions-2026-10-29.md:6652`）：

```
「第 i 个实参是切向」是被调方提升后的类型已经说了的事（`liftedShapeOf` 的读法），在调用节点上另记一份
`tangentArgs`，又在记录缺席时回落到「签名前一半」的算术，是同一事实的两份真相加一条静默回落。
改为：`split` 从被调方的类型读切向位置（与 `lift.h` 同一个读者）；类型读不出时按名字拒绝，不回落算术。
```

两处的对象不同：

| 站点 | 问的是什么 | 被调方是谁 |
|---|---|---|
| `:1558` `ordinary / 2`（`answersAPair` 那一支） | 这个调用把哪些实参交给了一个**答对 `(value, tangent)` 的**被调方 | 提升后的图，签名就是 `Lift<F>` |
| `:1594` `callTangentArgsOf`（`else` 那一支） | **规则**把它自己的切向写在右式第几个实参上 | 一个普通库函数（`mul_tangent`、`pick_at`…） |

`96143dbb0` 改的是 `Half::halfInputsOf`，它问的正是**第一行**那个问题（`callValueSignatureOf`／被调方签名 → `valuePortsOf`），所以那一格和 `:1558` 是同一件事，**该统一**。

## 三、为什么类型说不出同一件事（三条，都不依赖读数）

1. **`pick_at` 的右式把切向写在第一位。** `stdlib/rulesets/jvp.cml:909`：

   ```
   index_into(xs, i) => (dxs: T[]) => pick_at(dxs, i, len(xs))
   ```

   位图记的是第 0 位（`dxs` 是这条规则的切向端口）。而被调方是 `tensor.cml:106` 的
   `pick_at(t: T[...], position: int, length: int)` —— **三个普通参数**，`valuePortsOf` 对奇数个端口
   返回空集：类型对这件事**一个字都答不出**（按裁定只能按名字拒绝）。
2. **同型的签名分辨不出切向。** `autodiff.cml:102` 的 `mul_tangent::<T>(x: T, w: T, dx: T, dw: T)`
   与一个纯四参函数（`max4(a, b, c, d): T`）**类型完全相同**。`valuePortsOf` 对两者都答「值端口 = 前两个」，
   于是那条「读法」退化成 `count / 2` 的算术加一次分辨不出差别的前缀校验 —— 裁定要消灭的正是这个。
3. **位图是位置无关的，类型不是。** 位图一个位置一位，规则把切向写在首、尾、中间都记得住
   （`rule_expand.cpp:1205-1224` 的注释逐字这样说）；类型只有「值在前、切向在后」这一种排法。

⇒ 三条合起来：**位图不是类型的第二份拷贝**，它是这条规则的右式怎么写的唯一陈述。把它换成类型读，
在 `mul_tangent` 这一族上恰好对（它们本来按「值在前」写），在 `pick_at` 那一族上就是错答案。

## 四、三条路与代价

| 路 | 做什么 | 代价 |
|---|---|---|
| **A（默认，已备好）** | 只把 `:1558` 的 `ordinary/2` 换成 `valuePortsOf`，读不出按名字拒绝（`skip=tangent`）；`:1565` 留位图；位图不删 | 一处读法不一致：同一个调用，值半问类型、晚节点读位图。但两者问的是不同的事，注释已写明 |
