# 模块改名的“图身份”，该不该钉成整张图的摘要

**状态**：等负责人回答（默认见末节：把摘要换成逐字段断言，不重录）

## 问句

`test/cases/modules/rename/identity.mjs` 用一个**归一化整图 sha256** 来证明“改名只改模块名”：
它把文档里所有字符串中的模块名前缀替换成 `MODULE:`、把检出绝对路径替换成 `CASE/`、删掉 `origin` 字段，
然后对整个 JSON 求摘要，与 `CASES[key].expected` 比。

问题：**这个摘要把“改名”和“图按设计发生的任何其他变化”搅在一起** —— 结构一变（算子 id 表、资源名、节点编号、边的种类）
摘要就变，而它与“改名有没有多改别的”无关。它红的时候无法区分“改名多改了”与“图按设计变了”，只能靠人重录。

## 读数

```
出现位置：`test/plans/feat/modules/rename_identity.plan.toml` 的 `rename.env_graph_identity` / `rename.process_graph_identity`
         （以及 `mm.gc_poison_sweep` 对同一条用例的清扫副本，共 3 条红）
`identity.mjs` 的头注释自己列了四次“recorded once more”：
  · 资源 `io:stdout` 改名 `stdout` 时重录 · `std::jgir` 打印节点源名时重录（删 name 字段可复现旧值）
  · 图开始写“两个效应在同一资源上的顺序边”时重录 · `std::jgir` 按规范顺序编号节点时重录
⇒ 每换一次 jgir 写法就得重录一次 —— 这是**快照**的行为，不是判据的行为
当前：`env` 的摘要 `019e3cb8…`，recorded `888f2f44…`（晋级 21 第一次红，此前 promo19/20 干净）；
      `process` 的摘要 `75712dab…`，recorded `a47eb096…`
窗口内按设计变过图的地方（读数，不是推断）：
  `c67977b020` 算子按 id 表识别数组形 · `c65c0bf6b6` 三个标准资源并成一个（`uses var console, env` 就是它）· 节点编号规则
反向替换试过 14 种（`console→stdout`、`uses var console→uses stdout`/`→uses io:stdout`、去掉 `var `、`:op/→:`、`:io/→io:` 及其组合）
**没有一个等于 recorded** ⇒ 差异不止资源名，`identity.mjs` 想证的属性（新拼写在、旧拼写不在）实测**成立**（`env:` 2 次、`sys:` 0 次；`process:` 3 次、`os:` 0 次）
```

## 两边的理由

**继续钉摘要（重录）**
```
· 一条断言就能证“整张图只差模块名”，最强
· 已经有四次重录的先例
```
**改成逐字段/名字级断言**
```
· 摘要无法区分“改名多改了”与“图按设计变了”⇒ 红的时候给不出“哪里不对”，只能重录；重录等于把当下的差异固化
· 它想证的属性本来就是“新拼写在、旧拼写不在” —— `identity.mjs:142-146` 现成的两条断言已经是这个形状（`includes(\`${now}:\`)`、`!includes(\`${old}:\`)`）
· 结构变化由**别的**用例负责（graph golden、快照计划），不该在这一条里重复承担
```

## 默认（不等回答也照这个）

**不重录摘要；把“图身份”改成名字级断言**：
```
① 保留 `!includes(old:)`、`includes(now:)` 两条（已有）
② 加一条“除模块名外，两个样本（`_old` 与 `_new` 同名兄弟）的归一化文档逐字段相同” —— 用例目录里已有
   `env_old.cml`/`env_new.cml`、`process_old.cml`/`process_new.cml` 这对兄弟，正是为这件事准备的比较对象
③ 摘要可以留着当“今天这张图长什么样”的记录，但**不再作为判据**；它红时按“快照过期”处理，不阻塞晋级
```
⇒ 在这条定案前，这 3 条红记为“**钉按设计过期**”，不是行为回归，也不重录。

## 影响面

- 不阻塞 `develop`：这 3 条在晋级 21/25 的红表里已属“已知红”。
- 改法落在测试与工具面（元层），不是 `src/`；谁来做由决策者那边定。
## 答复（决策者）

同意默认：不重录摘要，改成名字级断言（新拼写在、旧拼写不在），再加"除模块名外，两个同名兄弟样本的归一化文档逐字段相同"。整图摘要是快照，图按设计每变一次就要重录，红的时候说不出哪里不对；图的结构由图金标负责。
